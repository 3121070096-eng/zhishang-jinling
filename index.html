官方资料 ↗

工坊图样为原创数字练习，并非传承人作品或传统纹样复刻。对称折剪是通用模拟，不能代表南京剪纸的全部技法。展台光影与视觉纸厚属于数字表现，不模拟真实剪刀、纸纤维断裂或手工可剪性。

AI创意赛道说明：生成式/规则式能力实质参与核心互动——工坊「AI 灵感起稿」含「词灵感」（本地规则引擎，确定性种子 + 对称几何）与「照片起稿」（本地阈值/色调分离→轮廓，图片不离开浏览器）；二者皆生成虚线建议轮廓，不调用云端大模型，也不假装在线 API。剪口仍由人手落下。AI 另参与交互构思、视觉与代码协作。本人负责：资料核对、审美选择、人手落剪与演示讲述、个人信息填写。实际协作经过请以真实记录为准。

GitHub调研参考：PAPERCUTTING.art 与 Paper.js。上述项目仅作初版调研。第二版使用 Three.js（MIT 许可）呈现纸张光影；动画时序参考 GSAP Observer / ScrollTrigger、倾斜交互参考 Vanilla Tilt，代码自行实现。分镜切镜为本地 Hybrid Deck，无 Barba/Swup。国风展陈参考 GitHub 上的故宫主题网站练习 museum，未复制其代码、字体或图片。
